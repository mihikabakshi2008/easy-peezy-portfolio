Featured Project

🌸 Easy Peezy – Accessibility-Focused Android Assistant

Easy Peezy is an Android application currently under development, designed to make everyday digital services more accessible to elderly users.

Key Features:
- Simple interface with large, easy-to-use touch targets.
- Voice-assisted navigation.
- Multilingual support: English, Hindi and Bengali.
- Access to food delivery, grocery ordering, cab booking and family contacts.
- Accessibility-focused interactions designed for older adults.

Technology Stack:
- Flutter
- Dart
- Android SDK

Project Status: Under active development.
